Yoke is the modular accessory series in the RyzoBee / Root ecosystem, quickly adding displays, lighting, sensing, voice, motors, touch, power, and other functions to Root controllers.

Standardized interfaces and a consistent module design reduce complex wiring and hardware integration barriers, helping makers, 3D printing creators, and developers build, test, and recreate projects faster.

## What Is Yoke?

Yoke is an expansion module system designed around the Root controller series.  
Each Yoke module serves a specific function, such as lighting, environmental sensing, voice interaction, motor control, or battery power.

Users choose Yoke modules according to project needs and connect them through standard Root controller interfaces to quickly add electronics to 3D prints, desktop devices, interactive models, or development projects.

Yoke is designed to:

- Make electronic modules easier to connect

- Make project functions easier to reproduce

- Make it easier to add interactivity to 3D prints

- Let creators spend more time on their ideas and creations instead of complex wiring and low-level drivers

  

## Interface Types

Yoke modules use different interface types to connect to Root controllers according to their functional and mechanical requirements.

Yoke accessories currently use the following main interface types:

| Interface Type | Description | Typical Modules |
| --------------------- | ---------------------------------------------------- | ------------------------------------- |
| [RS-Port](#P_RS_PORT) | Small sensors, lighting, buttons, touch, and motor modules | Yoke-TRGBW, Yoke-RAD60, Yoke-MOTO |
| [F-BUS](#P_F_BUS) | Touch displays, thermal imaging, USB PD motor driving, and other expansion functions | Yoke-LCD1D54C, Yoke-THERM5K, Yoke-MOTOR-A |
| [S-BUS](#P_S_BUS) | Dedicated expansion modules such as voice and audio | Yoke-VOICE |

## Basic Workflow for Yoke Modules

1. Choose the Yoke modules needed for your project.
2. Confirm that the Root controller supports their interface types.
3. Connect the modules with the power off.
4. Follow the [Zoner Quick Start](/en/Zoner/quick_start) to choose a project matching your controller and modules.
5. Flash or configure the firmware.
6. Power on and check the module status.
7. Install the modules and cables according to the project structure.
8. Save the configuration and complete assembly.

## Using Yoke with Zoner

[Zoner](/en/Zoner) provides project resources, firmware deployment, and device management.
In Zoner, users can find project examples, firmware resources, configuration instructions, and assembly guides for Yoke modules.

Zoner helps users quickly:

- Find project templates supported by a module
- View module connection instructions
- Download or flash firmware
- Configure module parameters
- Obtain assembly instructions
- Recreate official projects

Check each project detail page for deployable firmware, supported modules, and configuration options. A module having a Wiki page does not mean every project supports it.

## Usage Precautions

When using Yoke modules, observe the following:

- Connect or disconnect the module with the power off.
- Check connector orientation before use to avoid reversed connections.
- For high-power modules, make sure the Root controller can supply enough power.
- Pay particular attention to current and heat dissipation for motor, lighting, wireless power, and battery modules.
- Interface definitions may vary between hardware revisions. Refer to the documentation for your actual revision.
- If a module behaves incorrectly, first check power, cables, connector orientation, and firmware configuration.
- Frequent connection or disconnection of Yoke modules while powered on is not recommended.

### Can Yoke modules be hot-plugged?

Hot-plugging is not recommended.  
Connect or disconnect Yoke modules with the power off to prevent connector short circuits, communication errors, or module damage.

### Can one Root controller connect to multiple Yoke modules?

Yes, depending on the Root controller's interface count, pin usage, mounting space, firmware support, and total power capacity. Sharing an interface type does not mean modules can be stacked in any combination.
Pay particular attention to the power margin when using several high-power modules, such as lighting, motors, and displays.

### Do Yoke modules need to be flashed separately?

Most Yoke modules do not need separate firmware flashing. The Root controller runs the project firmware and controls the modules.  
Some complex modules may need dedicated configuration or driver support. Refer to the relevant module page.

### Are Yoke modules only for RootMaker?

Yoke modules are primarily designed for the Root controller series.  
Other Root controllers can use the corresponding Yoke modules if they provide the same interfaces and firmware support.

### What if a module is not recognized?

Check the following:

1. Is it connected to the correct interface?
2. Is the connector orientation correct?
3. Is the Root controller powered correctly?
4. Does the firmware support this module?
5. Is the correct module selected in Zoner or the project template?
6. Is the cable damaged or making poor contact?

### What if lighting, motors, or displays behave incorrectly?

This is usually related to insufficient power, poor connector contact, or mismatched firmware configuration.  
First reduce the load, check cable connections, and confirm that the current project template matches the actual modules.
