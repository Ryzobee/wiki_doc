[我的设备](https://zoner.ryzobee.com/device) 是 Zoner 的统一设备连接入口。连接后可读取固件支持的状态、发送配置，并使用本地固件烧录工具。

## 连接与状态

使用 USB 数据线连接主机与电脑，在页面点击“连接 RootMaker”，选择对应串口并授权。连接失败时，参考 [连接故障排查](/zh/Zoner/quick_start#troubleshooting)。

“设备信息”区域可显示 CPU、RAM、PSRAM、网络状态、Wi-Fi 和 IP 地址；可用时点击“刷新状态”重新读取。具体字段依赖当前固件返回的信息，未返回的内容可能显示“—”。

USB 串口连接与 Wi-Fi 联网是两件事：设备能够通过 USB 通信，不代表它已接入无线网络；完成配网也不能代替浏览器对 USB 串口的授权。

## Wi-Fi 配置 <a id="wifi"></a>

1. 确认设备已连接，且当前固件支持 Zoner 配网。
2. 在“Wi-Fi 配置”中选择设备扫描到的网络。
3. 对于隐藏网络或没有扫描结果的情况，使用“手动输入网络名称”并填写 SSID。
4. 输入 Wi-Fi 密码，点击“保存 Wi-Fi 配置”。
5. 等待设备尝试连接，在“设备信息”中检查网络状态与 IP 地址。

RootMaker 使用 2.4GHz Wi-Fi，请确认网络频段与设备兼容。配置保存成功不等于已经联网成功，仍需检查连接结果。

如果当前项目使用自己的配网流程，请优先遵循项目说明。反馈问题时不要公开 Wi-Fi 密码。

## 自定义配置 <a id="custom-config"></a>

页面提供 3 组字符串配置，对应 `slot1`、`slot2`、`slot3`。这些字符串的用途由项目固件决定，应先阅读项目对每一项的定义。

1. 勾选需要修改的项。
2. 填写项目要求的字符串内容。
3. 点击“保存自定义配置”。
4. 按项目说明验证设备是否采用新配置。

未勾选的项保持原值。当前页面说明协议不支持读取原值，因此空白输入框不代表设备中没有保存配置；不要为了“补齐”输入框而覆盖不需要修改的项。

## 本地固件烧录 <a id="local-firmware"></a>

优先通过项目详情页部署已匹配的固件。只有在项目作者或开发流程明确提供了适用于本入口的文件时，才使用本地烧录。

当前“固件烧录”入口面向 **ESP32-S3 合并固件**，接受 `.bin` 文件，页面标注大小上限为 **16 MiB**，写入地址为 **`0x0`**。文件大小符合限制不代表固件与硬件兼容。

1. 确认文件适用于目标主机、Flash 容量及硬件版本。
2. 确认它是以 `0x0` 为写入起点的合并固件；不要把仅含应用程序的 `.bin`、单独的 bootloader 或分区表当作合并固件。
3. 备份设备重要文件及配置，关闭占用端口的其他工具。
4. 在“固件烧录”区域选择或拖入文件，核对页面显示的信息。
5. 点击“开始烧录”，按页面提示完成操作并等待成功。
6. 如有提示，重启或重新连接主机，验证固件运行情况。

烧录会覆盖写入范围内的现有内容。不要在过程中断开 USB、切换电源或按下 Reset；如项目包含 Yoke-MOTOR-A 等特殊供电模块，先遵循模块文档确定正确的烧录接线方式。

## 连接与烧录日志

展开“连接与烧录日志”查看连接或写入过程。出现错误时，优先记录首次错误及前后的少量日志，并附上主机型号、固件来源和文件版本；反馈前移除密码、密钥等敏感内容。

## 常见问题

### 已连接，但设备状态没有更新

检查固件是否支持状态读取、设备是否在正常运行状态，再尝试“刷新状态”。如果仍在下载模式，应先按主机或项目说明恢复运行。

### Wi-Fi 或自定义配置按钮不可用

先确认串口已连接、设备运行兼容固件且没有进行其他操作。不能仅通过刷新网页让不支持该协议的固件获得配置能力。

### 能直接烧录普通 ESP32 或其他开发板的固件吗？

本入口标注面向 ESP32-S3，仍需确认 RootMaker 的实际硬件配置。芯片名称相同也不保证 Flash、引脚与分区布局一致，请使用明确匹配的固件。
