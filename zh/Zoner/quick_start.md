本指南帮助你通过 Zoner 将一个匹配硬件的项目部署到 RootMaker。尚未了解产品体系时，可以先阅读 [产品快速入门](/zh/fast_guide)。

## 1. 准备硬件与浏览器

- 准备项目需要的 RootMaker、Yoke 配件和供电设备。
- 使用支持数据传输的 USB-C 线缆；仅能充电的线缆无法用于串口连接。
- 在电脑上使用 Chrome 或 Edge，打开 [Zoner](https://zoner.ryzobee.com)。
- 关闭正在占用同一串口的串口监视器、开发工具或其他浏览器标签页。

先阅读模块供电说明，在断电状态下按要求安装模块。首次验证时可暂缓封装外壳，便于检查接线和访问 USB 接口。

## 2. 选择项目并核对资料

打开 [所有项目](https://zoner.ryzobee.com/projects)，按分类或名称查找项目。进入详情页后依次查看：

1. **项目介绍：**确认作品功能和操作方式符合预期。
2. **模块与接线：**核对主机型号、硬件版本、Yoke 型号、供电和接线。
3. **项目文件：**检查固件与其他资源是否齐全，阅读对应版本说明。

在部署区域确认“主机型号”和“项目版本”。选择版本时优先考虑与实际硬件匹配，而不是仅选择版本号最大的固件。若项目只有案例资料，先按作者的说明准备文件，不要使用其他项目的固件代替。

## 3. 连接设备

1. 按主机和模块的供电说明连接电脑，保持 USB 数据连接稳定。
2. 打开 [我的设备](https://zoner.ryzobee.com/device)。
3. 点击“连接 RootMaker”。
4. 在浏览器串口选择器中选择该主机的端口并授权连接。
5. 检查页面连接状态和日志，确认连接成功。

电脑同时连接多个串口设备时，请核对设备名称，必要时先断开其他无关设备。端口号会因电脑和 USB 接口不同而变化，不要固定选择某个 COM 编号。

设备信息由固件返回。如果状态为空或显示“—”，请先确认固件支持状态读取，不能仅凭这一现象判断硬件故障。

## 4. 部署项目固件

1. 返回已核对的项目详情页，确认主机和项目版本。
2. 备份当前设备中的重要脚本和数据，并记录需要保留的项目配置。
3. 点击“一键部署到设备”，按页面提示完成连接、固件确认及烧录。
4. 等待页面明确显示完成；期间不要拔下 USB 线、切换供电或按下 Reset。
5. 如页面提示重启或重新连接，按提示操作，再检查设备状态。

烧录会覆盖写入范围内的数据。对于包含脚本分区的完整固件，原有 Lua 应用及其存储数据可能被覆盖。所需时间与固件大小、下载速度和串口连接有关，请以进度与完成提示为准。

使用本地 `.bin` 文件时，请查看 [本地固件烧录](/zh/Zoner/device#local-firmware)，不要将任意固件文件直接用于该入口。

## 5. 验证项目运行

先在便于检查的状态下测试项目，再进行最终装配：

1. 检查主机是否正常启动，屏幕、灯光或其他状态是否符合项目说明。
2. 逐项测试按键、触摸、传感器、语音或电机等项目功能。
3. 项目需要联网时，按 [设备管理](/zh/Zoner/device#wifi) 或项目自己的说明完成配网。
4. 记录可正常运行的项目版本和硬件组合。
5. 断电后完成外壳、模块和线缆固定，再上电复测。

首次测试电机项目时，先确认机构没有被卡住，并遵循模块页面的供电和调速说明。

## 故障排查 <a id="troubleshooting"></a>

### 找不到连接按钮或浏览器不支持串口

使用电脑上的 Chrome 或 Edge，通过 HTTPS 打开 Zoner；避免在聊天应用的内置浏览器中操作。检查浏览器是否禁用了串口权限，或被组织策略限制。

### 串口选择器没有设备

依次检查 USB 线是否支持数据传输、USB 接口是否正常、主机是否供电、操作系统是否识别设备。可以更换数据线和 USB 接口；若系统提示需要驱动，请按对应硬件说明安装。

### 端口存在，但连接失败或提示被占用

关闭 Arduino 串口监视器、其他烧录工具和占用端口的浏览器页面，再重新连接。确认选中的端口属于目标主机；如固件状态异常，按主机说明进入下载模式后重试。

### 项目无法部署或固件下载失败

确认项目提供可部署固件、版本与主机匹配，且网络可以访问资源。记录具体错误和项目链接，避免连续更换不相关固件试错。

### 烧录中断或失败

查看“我的设备”中的“连接与烧录日志”，记录最先出现的错误。检查数据线、供电和端口占用情况，按主机说明恢复下载模式后重新烧录匹配的完整固件。烧录过程中不要强行插拔模块。

### 烧录完成，但模块没有反应

确认已经退出下载状态并运行项目固件；再检查模块型号、接线、供电和项目配置。断电后重新插接模块。模块 Wiki 可用不代表当前项目固件支持该模块。

### 仍然无法解决

整理项目链接与版本、硬件型号、操作步骤及错误日志，按 [Zoner 获取帮助](/zh/Zoner#获取帮助) 中的方式反馈。
