Ryzobee Link（侧栏名称为 **R-Link Beta**）是 Zoner 中用于 RootMaker Lua 开发的工作区。它提供脚本编辑、设备脚本管理、UI 模拟器和运行日志。

[打开 R-Link](https://zoner.ryzobee.com/link)

## 使用条件

设备端功能需要先烧录兼容的 [Ryzobee Link 项目固件](https://zoner.ryzobee.com/projects/z000001)。烧录前请核对项目主机和版本，并备份设备已有的脚本与数据；完整固件烧录可能覆盖脚本分区。

在 [我的设备](https://zoner.ryzobee.com/device) 连接 RootMaker 后，再进入 R-Link。平台共用同一个设备连接入口，无需在 R-Link 中另行连接。未连接时仍可编辑草稿和使用页面提供的 UI 模拟器，但不能管理设备内的文件。

## 创建、打开与备份脚本

1. 点击“新建脚本”，或通过“打开文件”载入本地 Lua 文件。
2. 在“Lua 工作区”核对文件名并编辑内容，通过文件标签切换已打开的草稿。
3. 查看编辑区下方的保存状态和字节数提示。当前页面显示的脚本大小上限为 16 KiB。
4. 使用“导出”将重要脚本保存到电脑。

草稿保存在当前浏览器。更换浏览器、清理网站数据或丢失本地环境后，不能依赖草稿恢复工作；需要保留的内容请及时导出。

## UI 模拟器

点击“运行模拟”，可在浏览器的 240 × 240 模拟屏幕中预览受支持的界面内容，并通过“模拟器”日志查看运行信息。

模拟器仅模拟 UI，不控制设备。实际显示效果、触摸、传感器、电机、语音和联网功能仍需在匹配的主机、模块与固件上验证，不能将模拟成功当作硬件验证完成。

## 发送与管理设备脚本

1. 在“我的设备”连接运行兼容 R-Link 固件的主机。
2. 返回 R-Link，确认设备连接状态。
3. 核对当前草稿的文件名和内容，点击“发送到设备”。若出现同名文件处理提示，先确认设备中的原文件是否需要备份。
4. 使用“刷新设备脚本”查看设备返回的文件列表，并检查设备存储信息。
5. 按设备脚本列表或主机应用界面提供的操作运行脚本，查看运行日志并验证实际效果。

编辑草稿、发送文件和运行设备脚本是不同操作。浏览器显示草稿已保存，不代表脚本已经写入主机；文件发送完成后，也应确认它是否已运行。

## 日志与设备 Console

“运行日志”可以按“全部”“设备”“模拟器”筛选，便于区分浏览器预览和真实设备输出。排查问题时先确认日志来源，再记录错误位置及复现步骤。

连接支持的设备后，可按项目或固件文档使用设备 Console。命令由固件定义，不要将电脑终端命令直接粘贴到设备 Console。

## 常见问题

### “发送到设备”不可用

检查“我的设备”是否连接成功、主机是否运行兼容 R-Link 固件，以及当前草稿是否满足页面的文件名与大小要求。

### 看不到设备脚本

先检查连接，再刷新设备脚本。普通项目固件不一定支持 Lua 文件管理；确认已安装 R-Link 项目要求的固件。

### UI 模拟正常，设备上运行异常

核对固件提供的 Lua API、硬件型号与接线，并查看“设备”日志。模拟器只覆盖 UI 预览，不能替代设备测试。

### 更新固件后脚本丢失

完整固件可能覆盖脚本分区。使用此前导出的备份恢复所需脚本，并重新发送到兼容固件；更新前应先备份设备文件。
