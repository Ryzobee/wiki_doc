## 设备连接问题

本分类用于排查 RootMaker 与电脑、USB-C 线缆、电源适配器之间的连接问题。

常见问题包括：

- RootMaker 插入电脑后没有反应
- 电脑无法识别 USB 设备
- 串口列表中找不到设备
- 设备反复断开和重连
- USB-C 线只能供电，无法烧录或调试

建议优先检查：

1. USB-C 线缆是否支持数据传输。
2. 电脑 USB 接口是否正常。
3. RootMaker 是否正常上电。
4. 是否需要进入下载模式。
5. 是否有外接模块导致供电异常。

## Wi-Fi 与网络问题

本分类用于排查 Wi-Fi 配网、网页控制、OTA、云端服务和网络连接相关问题。

常见问题包括：

* Wi-Fi 配网失败
* 设备无法连接路由器
* 浏览器无法打开设备网页
* OTA 更新失败
* 云端服务无法访问
* 局域网内找不到设备

建议优先检查：

1. Wi-Fi 是否为 2.4GHz 网络。
2. SSID 和密码是否正确。
3. 路由器是否限制新设备接入。
4. RootMaker 与路由器距离是否过远。
5. 天线区域是否被金属结构遮挡。
6. 项目固件是否支持当前网络功能。

## 安全与使用注意事项

使用 RootMaker 和 Yoke 模块时，请遵守基本电子产品安全要求。

请特别注意：

* 不建议在通电状态下插拔模块。
* 不要让金属物体接触接口或 PCB。
* 不要超过主机或模块的额定供电能力。
* 灯光、电机、电池和无线供电模块可能产生较高电流或温升。
* 儿童使用时应在成年人指导下操作。
* 若设备出现异常发热、异味或冒烟，请立即断电并停止使用。
