## Root主机系列


Root 主机系列是 Ryzobee 面向 Maker、3D 打印爱好者、创意开发者与教育场景设计的模块化智能控制主机系列。

Root 主机可以作为 3D 打印作品、创意装置、桌面机器人、灯效作品、传感器项目和交互设备的核心控制单元。通过统一的模块接口、可视化工具、示例项目和配件生态，用户可以更快速地完成从想法到可展示作品的制作过程。

通过 Root 主机，用户可以快速连接屏幕、灯效、传感器、音频、电机、电池等模块，并结合 Zoner平台、示例固件和项目模板完成作品开发。

## 接口与配件生态

Root 主机通过统一的接口与 Yoke 配件模块连接，构成完整的 Ryzobee 模块化生态。

常见接口包括：

| 接口    | 说明                                         |
| ------- | -------------------------------------------- |
| RS-Port | 常用于侧边模块、线缆连接模块与外部扩展       |
| S-BUS   | 常用于传感器、电池等底部扩展模块             |
| F-BUS   | 常用于屏幕、传感器、电池等上层或背部扩展模块 |
| USB-C   | 用于供电、下载固件、调试或数据通信           |

## 供电说明

Root 主机通常通过 USB-C 供电，也可以根据型号和项目需要连接电池模块或外部电源模块。

使用时请注意：

> **Warning**  
> 请确认外接模块的总功耗不超过主机或供电模块的额定输出能力。
{.is-warning}

> **Warning**  
> 灯带、电机、扬声器等高功耗外设建议使用独立供电或专用扩展模块。
{.is-warning}

> **Note**  
> 如果项目中包含多个高功耗模块，请优先查看对应主机页面中的供电建议。
{.is-info}

### Root 主机是否需要焊接？

大多数情况下不需要。Root 主机和 Yoke 模块主要通过标准接口、排线或连接线连接。

### 是否需要写代码？

如果使用官方示例固件和 Zoner平台，很多基础项目不需要写代码。  
如果需要自定义功能，可以使用 Arduino、ESP-IDF 或 MicroPython 进行开发。

### Root 主机是否可以直接控制 3D 打印机？

Root 主机主要用于控制 3D 打印作品或创意外设，不是 3D 打印机主控板。  
部分项目可以通过网络、串口或插件方式与 3D 打印机生态联动。

### Yoke 模块是否可以混用？

不同模块需要确认接口、电压、尺寸和软件支持情况。建议优先查看对应模块页面。

### 是否支持第三方模块？

部分接口可以连接第三方模块，但需要用户自行确认电气兼容性、驱动支持和安装方式。
